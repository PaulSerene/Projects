# 🚀 C++ Learning Journey — Roadmap

A complete, interactive C++ and Data Structures & Algorithms learning roadmap and progress tracker. Track your journey from C++ fundamentals all the way to advanced memory management, complex data structures, and competitive programming algorithms.

---

## ✨ Features

- **17 Domains** — Logically structured from beginner C++ to Advanced DSA and Engineering.
- **Topic Completion Tracking** — Comprehensive curriculum with individual checkboxes and XP rewards.
- **XP & Level System** — Earn XP for every topic completed and level up from *Novice* to master ranks.
- **Achievement System** — Unlock specific C++ and algorithmic achievements as you progress.
- **Current Quest** — Automatically suggests the next logical topic to tackle based on your progress.
- **Recent Activity** — Tracks your most recently completed topics.
- **Search** — Find any topic or algorithm instantly across the entire roadmap.
- **Filtering** — View All / Remaining / Completed / Core / Intermediate / Advanced / Optional.
- **Domain Progress** — Visual progress bars for each major learning area (e.g., OOP, STL, Data Structures).
- **Expand / Collapse** — Manage visual density as needed with global and section-level toggles.
- **Export / Import** — Backup and restore your progress via JSON files.
- **Reset** — Clear your C++ progress entirely and start fresh.
- **Persistent** — Progress is saved automatically directly in your browser's `localStorage`.

---

## 🗺️ Curriculum Overview

The roadmap progresses through the following carefully ordered domains:

1. **C++ Foundations** — Syntax, compilation, and basics
2. **Functions** — Declarations, passing by reference/value, lambdas
3. **Arrays, Strings & Memory** — Pointers, arrays, and string manipulation
4. **Structs, Enums & Program Structure** — Header files and custom types
5. **Object-Oriented C++** — Classes, inheritance, and polymorphism
6. **Modern C++** — Smart pointers, move semantics, and C++11/14/17/20 features
7. **Templates & Generic Programming** — Function and class templates
8. **STL** — Standard Template Library containers and algorithms
9. **Error Handling & File I/O** — Exceptions and streams
10. **Complexity Analysis** — Big-O time and space complexity
11. **Data Structures** — Linked lists, trees, graphs, hash tables, etc.
12. **Algorithms** — Sorting, searching, and graph traversal
13. **Problem-Solving Patterns** — Two pointers, sliding window, fast/slow
14. **Advanced DSA — Endgame** — Dynamic programming, advanced graphs, tries
15. **C++ Engineering** — Build systems (CMake), testing, and best practices
16. **Optional C++ Ecosystem** — Libraries and frameworks
17. **Boss Challenges & Practice** — Capstone problems and projects

## 🏆 XP & Levels

Every topic you complete grants XP based on its difficulty:
- **Easy:** +10 XP
- **Medium:** +20 XP
- **Hard:** +30 XP
- **Advanced:** +50 XP
- **Boss:** +100 XP

As you accumulate XP, you level up and earn new ranks, starting from **Novice**, proving your mastery over C++ and Data Structures.

---

## 🎯 Achievements

The roadmap includes a custom achievement system. Unlocking achievements requires mastering specific groupings of topics. For example, completing all memory management topics, finishing all sorting algorithms, or reaching a 50% completion milestone across the entire roadmap. 

---

## 🗂️ Data Independence

This roadmap stores its progress locally in your browser under the `localStorage` key: `cpp_dsa_journey_v2`.

---

## 🚀 How to Use

1. Open `C++ Roadmap.html` in any modern web browser (Chrome, Firefox, Edge, Safari).
2. Start from **Domain 01 — C++ Foundations**.
3. Check off individual topics as you learn and implement them.
4. Follow the **Current Quest** suggestion for the recommended next step.
5. Track your progression in the left sidebar and through the center domain bars.
6. Use the **Export** feature regularly to keep a backup of your journey.
