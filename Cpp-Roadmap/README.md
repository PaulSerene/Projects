# C++ & DSA Learning Roadmap

An interactive learning roadmap I built to track my journey through
C++, Data Structures, Algorithms, and problem-solving.

## 🚀 Features

- 📚 Structured C++ learning path
- 🧠 Data Structures & Algorithms progression
- ✅ Topic completion tracking
- ⭐ XP and leveling system
- 🏆 Achievements
- 🔎 Search and filtering
- 📊 Progress tracking
- 💾 Local progress persistence
- 📱 Responsive design

## 📖 What It Covers

The roadmap progresses through:

1. C++ Foundations
2. Functions
3. Arrays, Strings & Memory
4. Structs, Enums & Program Structure
5. Object-Oriented Programming
6. Modern C++
7. Templates & Generic Programming
8. STL
9. Error Handling & File I/O
10. Complexity
11. Data Structures
12. Algorithms
13. Problem-Solving Patterns
14. Advanced DSA
15. C++ Engineering
16. C++ Ecosystem

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

The project is completely standalone and does not require a backend,
database, or package installation.

## ▶️ How to Use

Open `C++ Roadmap.html` in a web browser.

Your progress is saved locally in your browser using `localStorage`.
