# 🐍 Python Learning Journey — Roadmap

A complete, interactive Python learning roadmap and progress, tracking your journey from Python fundamentals to advanced programming, automation, data science, and web development.

---

## ✨ Features

- **18 Domains** — Logically structured from beginner to advanced, covering all major Python topics
- **230+ Topics** — Comprehensive curriculum with individual checkboxes and XP rewards
- **XP & Level System** — 10 levels from *Newbie Byte* to *Python Master*
- **Achievement System** — 14 Python-specific achievements to unlock
- **Current Quest** — Automatically suggests the next best topic to tackle
- **Recent Activity** — Tracks your last 8 completed topics
- **Search** — Find any topic instantly across all domains
- **Filtering** — View All / Remaining / Completed / Core / Intermediate / Advanced / Optional
- **Domain Progress** — Visual progress bars for each learning area
- **Expand / Collapse** — Manage visual density as needed
- **Export / Import** — Backup and restore your progress as JSON
- **Reset** — Clear Python progress only (never affects C++ roadmap)
- **Persistent** — Progress saved automatically in `localStorage`

## 🗂️ Data Independence

This roadmap stores progress under the localStorage key `py_journey_v1`.

The C++ roadmap uses `cpp_dsa_journey_v2`.

**They are completely independent.** Resetting Python progress never affects C++ progress, and vice versa.

---

## 🚀 How to Use

1. Open `Python Roadmap.html` in any modern browser (Chrome, Firefox, Edge, Safari)
2. Start from Domain 01 — Python Foundations
3. Check off topics as you learn them
4. Follow the **Current Quest** suggestion for the recommended next step
5. Track your progress in the left sidebar and center domain bars
6. Export your progress regularly as a backup
